# 305 Car Rentals website

This repository holds a single landing page for 305 Car Rentals, a Miami car rental, black car, and airport transfer service.

This is a rentals and transfer site only. There are no prices, no for-sale or financing language, and no street address or email on the page.

## Files

- `index.html` — the only page (inline CSS).
- `images/hero-night.jpg` and `images/miami-daytime.jpg` — compressed promo photos used in the hero and gallery.
- `fonts/` — local Oswald and Outfit typefaces, so the page does not depend on an external font service.
- `CNAME` — points GitHub Pages at 305carrentals.com.
- `robots.txt` and `sitemap.xml` — basic search-engine files.
- `preview-desktop.png` and `preview-mobile.png` — local design previews, not part of the public page.

## Local preview

Open `index.html` in a browser, or from this folder run:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080/.
